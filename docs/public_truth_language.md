# Public Truth Language

Dizzy public surfaces should be clear, welcoming, and strict about what is actually known.

Use the narrowest truthful label:

| Label | Use when | Do not imply |
| --- | --- | --- |
| `verified` | A named local deterministic check or receipt passed for the exact stated scope. | Production readiness, external truth, or future runs. |
| `rehearsal` | A mock, fixture, in-process, sidecar, or dry-run boundary was exercised. | Promotion authority, live customer impact, or cross-runtime delivery. |
| `local` | The behavior was observed on this checkout or operator machine. | Hosted availability or universal portability. |
| `operator-mediated` | A human token, manual review, explicit approval, or local PowerShell step remains part of the path. | Autonomous completion or unattended operation. |
| `sample` | Data is seeded, fixture-based, demonstration-only, or copied for UI shape. | Real-time telemetry, actual payout eligibility, or current provider health. |
| `unknown` | The current surface has not measured or received the fact. | Failure, success, availability, or correctness. |
| `blocked` | A fail-closed rule stopped the action. | Partial success or hidden fallback. |

Public README, quickstart, dashboard, and collaborator handoff copy should prefer these phrases:

- `receipt-scoped evidence`
- `reported by local telemetry`
- `rehearsal-only`
- `local operator surface`
- `operator-mediated`
- `sample data`
- `unknown until checked`
- `blocked fail-closed`

Avoid copied-forward absolutes unless the same sentence includes the exact receipt path or command to refresh the claim:

- fixed audit counts or hashes
- `live` for demonstration data
- `proof` where the receipt is evidence only
- broad hosted-readiness claims
- unattended-autonomy claims
- live-public-interoperability claims
- model availability claims not derived from the current surface

The rule of thumb: a public sentence should tell a collaborator what they can check, what remains local, and what still requires an operator or promotion gate.
