---
name: security-review-stack
description: Perform evidence-based application security review and scanner triage with risk prioritization. Use for auth, secrets, APIs, databases, CI, dependencies, or trust-boundary changes.
---

- Map assets, actors, entry points, trust boundaries, and sensitive operations.
- Review reachable code and configuration before relying on scanner output.
- Classify findings by impact, exploitability, reachability, confidence, and detection time.
- Cluster related symptoms under the causal weakness.
- Mark scanner findings as confirmed, likely, uncertain, or false positive with evidence.
- Provide developer-readable remediation and a concrete verification test.
- Avoid compliance theater, unprioritized warning floods, and unsupported exploit claims.
