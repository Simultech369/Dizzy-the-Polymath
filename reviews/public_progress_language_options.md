## Not Allowed Yet

Do not use:

- "Active policy is complete."
- "Dashboard containment is verified."
- "Consensus resolved containment."
- "Cryptographic review/signature/attestation."
- "Sandbox/time-travel rollback."
- "Autonomous containment authority."
- "Live-agent consensus."
- "Production-ready containment."
- "All safety checks pass."

## Drafting Suggestions While Waiting

Useful internal drafts Codex can prepare for Simul approval, if needed:

- one-paragraph public update using the current-checkpoint language above;
- a short Antigravity return message that links `reviews/antigravity_return_packet.md`;
- a post-commit review template based on `reviews/first_commit_acceptance_checklist.md`;
- a release-note stub with placeholders for commit SHA, evidence commands, and side-effect receipt;
- a "what changed / what did not change" note after Antigravity's first candidate commit.

Avoid drafting:

- README claims before evidence exists;
- HUD copy before backend boundaries pass;
- model-review summaries that imply model agreement is authority;
- public explanation of private reviewer context, provider details, or dirty local paths.
