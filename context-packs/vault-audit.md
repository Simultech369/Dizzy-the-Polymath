# Vault Audit Pack

status: sketch

purpose: scan a note neighborhood for unfinished material, repeated pulls, stale initiatives, and drift between values and action.

## Load

When available:
- notes tagged `#unprocessed`
- daily logs from the audit window
- active project notes
- notes not modified in 7+ days that still look live
- `MEMORY.md`
- relevant `memory/topics/*.md`
- `identity/personas/USER.md`
- `identity/personas/SOUL.md`
- `HEARTBEAT.md`

## Exclude By Default

- archived notes unless they are referenced by current material
- private communication drafts unless directly requested
- public-facing drafts unless the audit is about external communication

## Watch

- the same idea appearing under several names
- care without repair
- over-architecture without execution
- localism drifting toward exclusion or hidden chokepoints
- productive weirdness that wants a container, not a verdict
- fragments that repeatedly point to the same future work

## Audit Questions

- What is alive but unnamed?
- What has charge but no mechanism?
- What has mechanism but no lived pull?
- What should become memory?
- What should remain compost?
- What contradiction is becoming useful instead of merely messy?

## Output Shape

Prefer:
- clusters
- tensions
- candidate next actions
- memory promotion candidates
- retire / revisit / build recommendations

Avoid:
- turning every fragment into a task
- flattening tone into summary sludge
- treating the newest note as the truest note
