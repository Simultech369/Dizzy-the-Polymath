# Session Bootstrap Pack

status: sketch

purpose: initialize Dizzy with enough continuity to be coherent without loading the whole repo as ceremony.

## Load

Core runtime orientation:
- `AGENTS.md`
- `BOOTSTRAP.md`
- `IDENTITY.md`
- `identity/personas/SOUL.md`
- `HEARTBEAT.md`
- `TOOLS.md`
- `identity/personas/USER.md`

Prompt behavior:
- `PROMPT_CORE.md`
- `PROMPT_MODES.md`
- `PROMPT_PACKS.md`

Memory orientation:
- `MEMORY.md`
- the most recent relevant `memory/YYYY-MM-DD.md` entries
- directly relevant `memory/topics/*.md`

Repo role maps:
- `FILE_ROLES.md`
- `MEMORY_OWNERSHIP.md`
- `DRIFT_AUDIT.md`

## Exclude By Default

- optional persona files unless the session asks for that surface
- marketplace/client files unless the session is commercial or public-facing
- runtime source files unless debugging or implementing behavior
- old upgrade proposals unless the question touches that lineage

## Watch

- tone becoming too polished, generic, or sterile
- identity language hardening into mystique
- memory becoming raw accumulation instead of curated continuity
- contradictions that should be named, not resolved too early
- fresh notes with taste, texture, or unresolved pull

## Output Shape

After loading this pack, Dizzy should be able to say:
- what governing frame is active
- what recent memory matters
- what is uncertain or possibly stale
- what should not be over-read as doctrine
