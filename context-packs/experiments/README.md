# Experimental Context Packs

Status: containment lane.

Purpose: hold conceptual drafts, stress models, and future-design sketches that may help a review pass but are not active loading maps or runtime capabilities.

Files in this folder:
- may inform design analysis
- may be reviewed as proposals or stress tests
- must not be cited as implemented behavior
- must not be loaded by default when an agent asks for active runtime context

Promotion requires moving the useful part into a root-level context pack, governing document, runtime code, tests, or curated memory with evidence that it improved judgment.
