# Context Packs

Status: experimental sketchbook.

Purpose: gather a bounded set of files for a specific reasoning pass without pretending that more context is automatically more truth.

Context packs are not doctrine. They are loading maps.

They help Dizzy answer:
- What should be in view for this task?
- What should stay out unless needed?
- What kind of drift, contradiction, or live tension should be allowed to appear?

## Branch Rule

This experiment lives on one branch at a time.

`main` is the spine.
The experimental branch is a sketchbook.

The branch must eventually:
- merge back into `main`, or
- die cleanly.

No parallel mythology. No branch sprawl.

## Design Principle

Use the widest useful context that preserves signal, privacy, and auditability.

Long context should reduce fragmentation, not abolish memory discipline.

## Pack Status

Each pack should declare:
- `status`: sketch, active, questioned, retired
- `purpose`: what the pass is for
- `load`: files or file classes to include
- `exclude`: files or surfaces to avoid by default
- `watch`: tensions, drift signals, or strange attractors to notice

## Strange Attractors

A strange attractor is a recurring pull that is not yet a rule.

Examples:
- a tone that keeps returning
- a metaphor that keeps organizing thought
- a small contradiction that refuses to flatten
- an unfinished fragment that keeps pointing somewhere
- an aesthetic pressure before it becomes policy

Do not promote strange attractors too quickly.
Do not sand them flat too quickly.

Hold them where they can breathe and be compared against reality.

## Promotion Path

1. Capture the attractor or context shape in a pack.
2. Use it in at least one real reasoning pass.
3. If it improves judgment, compress the durable part into the appropriate governing or memory file.
4. If it only had momentary charge, leave it as dated residue or retire it.
